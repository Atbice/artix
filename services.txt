# dinit services auto-enabled by bootstrap.sh.
#
# Artix dinit layout:
#   - service definitions live in /etc/dinit.d/<name> (or /usr/lib/dinit.d/
#     for package defaults). Each is a declarative key=value file
#     (type=process, command=..., depends-on=..., etc).
#   - enable a service for boot with `dinitctl enable <name>`, which
#     symlinks it under /etc/dinit.d/boot.d/ so the `boot` target pulls
#     it in. NOT a symlink-into-runsvdir like runit.
#   - inter-service ordering is declared in the service file itself
#     (`depends-on = dbus`, `waits-for = seatd`), so dinit handles
#     startup order — we don't enforce it by enable-order here.
#
# Order in this file is informational. install.sh already enables
# dbus + seatd + turnstile + NetworkManager + zramen in the chroot, so
# bootstrap.sh's job is mainly the desktop-side services like greetd.
#
# Why seatd + turnstile (not elogind): elogind is a fork of systemd's
# logind. turnstile + seatd are from-scratch session/seat daemons with
# no systemd DNA. See docs/adr/0002-turnstile-seatd-over-elogind.md.
dbus
seatd
turnstile
NetworkManager
greetd
